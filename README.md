# crm-dashboard

#### 介绍
前期是想做一个明信片小程序.由于看到有人在做了,后期就没跟进了.这个个项目还有很多不完善的地方,比如明信片也的信息缺少,没有分享功能(推送明信片).

#### 软件架构
框架基于spring-boot + mybatis-plus + guava-limit（限流） + spring-boot-retry (重试机制)


#### 安装教程

小程序和数据库脚本 resource 下，wechat
